# Context

- **Intent:** canonical structured request shared by every interface.
- **Information:** read-only action completed in WhatsApp when requested there.
- **Preparation:** safe field collection that may create a preview but cannot execute.
- **Execution/sensitive:** irreversible or security-sensitive action requiring authenticated WebApp confirmation.
- **Handoff:** short-lived opaque token referring to authoritative server-side action state.
- **Paper execution:** explicitly labelled simulated provider execution.
- **WhatsApp adapter:** Meta-specific edge translation with no financial domain ownership.
