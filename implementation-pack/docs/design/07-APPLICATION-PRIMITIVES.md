# Application Primitives for Normal View

Normal View is familiar fintech UX expressed in ChatDex's visual language.

## Required V0 primitives
- App header
- Bottom navigation
- Segmented/surface switch (`Chat` / `Home`)
- Balance hero
- Quick-action row
- Asset row
- Market row
- Search field
- Watchlist row
- Position row
- Activity row
- Asset header
- Price/change display
- Chart container
- Time-range selector
- Buy/Sell action group
- Amount input
- Order review sheet/card
- Empty/loading/error states
- `Ask ChatDex` contextual action

## Familiarity rule
Normal View should behave like a financial app users already understand. Do not deliberately make navigation novel just to be different.

## ChatDex rule
Familiarity does not mean visual cloning. Preserve ChatDex typography, accents, geometry, card language and context bridge.

## Navigation
For V0 keep navigation restrained. Suggested destinations:
- Home
- Markets
- Activity

Chat remains available as a primary surface/switch, not buried in `More`.
