# Responsive, Mobile and PWA

## Priority
The supplied designs are phone-first and the WhatsApp venue makes mobile the primary V0 target. Desktop must remain usable but should not drive the visual decisions.

## Mobile
- respect safe areas;
- keep composer/navigation reachable;
- minimum 44×44 interactive targets;
- avoid horizontal overflow in cards;
- use sheets/drawers for compact workflows where appropriate;
- preserve card readability at common phone widths.

## Desktop/tablet
Do not stretch 264px financial complications into giant panels. Place compact components in sensible containers and allow Normal View to use wider information layouts.

## PWA
- manifest and install metadata;
- app icons;
- standalone display where appropriate;
- resilient loading shell;
- clear `Add to Home Screen` guidance as secondary to the WhatsApp pinned-link strategy.

## WhatsApp entry
A ChatDex link opened from WhatsApp must land cleanly in the mobile WebApp without requiring an installed app.
