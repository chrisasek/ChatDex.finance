# Flow 04 prototype brief

## Goal

Show the same completed NVDA paper order as a conversational receipt in Chat View and as portfolio/activity state in Normal View.

## Required transitions

- Chat ↔ Home surface switch
- Portfolio card → Home position detail
- Activity row → receipt detail
- NVDA position → Chat with structured NVDA context
- Loading, empty and error demonstrations remain reachable in the prototype controls

## Guardrails

Chat is primary. Quick Actions stay inside Chat. Home uses familiar finance navigation while preserving ChatDex tokens, compact dark financial faces, explicit Demo/Paper labels, mobile targets and reduced motion.
